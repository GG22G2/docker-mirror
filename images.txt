# ============================================================
# 要同步的镜像列表（编辑并提交本文件后，到 Actions 手动运行工作流）
#
# 每行一个镜像，# 开头为注释，字段用 | 分隔：
#   字段1: 镜像地址（必填）
#   字段2: 自定义tag（可选，不填则自动命名 ck:名称_版本）
#   字段3: 平台标记（可选）：all=全部架构，arm=ARM64；不填默认 amd64
#
# 示例（取消注释即生效）:
#   nginx:1.27                    → ck:nginx_1.27          (amd64)
#   redis:7.4 | my_redis          → ck:my_redis            (amd64)
#   alpine:3.20 | | arm           → ck:alpine_3.20         (arm64)
#   alpine:3.20 | my_tag | all    → ck:my_tag              (全部架构)
#
# 注意: all 模式推送的是多架构清单，阿里云控制台不显示镜像ID/大小，
#       属正常现象（拉取和运行都不受影响）
# ============================================================
