# 要同步的镜像列表（编辑并提交本文件后，到 Actions 手动运行工作流）
#
# 格式1: 镜像地址                     → 自动命名为 ck:名称_版本
# 格式2: 镜像地址 | 自定义tag         → 推送为 ck:自定义tag
#
# 示例（取消注释即生效）:
#   nginx:1.27-alpine                        → ck:nginx_1.27-alpine
#   redis:7.4                                → ck:redis_7.4
#   quay.io/prometheus/prometheus:v2.53.0    → ck:prometheus_prometheus_v2.53.0
#   redis:7.4 | my_redis_7_4                 → ck:my_redis_7_4
#
# 首次使用建议只放开下一行，跑通全流程验证:
hello-world:latest
